## 💻 Технические требования

### Рабочая среда:
- **Операционная система:** Windows 11 (учебные классы)
- **IDE:** Visual Studio Code
- **Система контроля версий:** Git + GitHub.com
- **Терминал:** PowerShell (pwsh) по умолчанию

### Требования к проектам:
- **Python проекты:** простые скрипты без внешних зависимостей
- **HTML/CSS проекты:** статичные страницы, готовые для GitHub Pages
- **Git workflow:** feature branches → Pull Request → merge to main
- **Документация:** README.md по профессиональному шаблону

### Команды для PowerShell (Windows 11):
```powershell
